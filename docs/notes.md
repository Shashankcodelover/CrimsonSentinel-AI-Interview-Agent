# Engineering Notes & Design Decisions

- **Client-Side Signal Extraction**: Diagnostic modules, coverage radars, and rubric scorecards evaluate candidate conversation text using client-side keyword and pattern heuristics.
- **Simulation and Mock Layer**: The interview API (`/api/interview`) and polygraph modal provide simulated data and scripted mock responses.
- **Local State Persistence**: Candidate sessions, bookmarks, and notes persist in browser `sessionStorage`.
